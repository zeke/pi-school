# pi-school

A free, self-paced course for learning [Pi](https://pi.dev), the minimal
agent harness. Modeled on
[opencode.school](https://github.com/opencodeschool/opencode.school).

## Status

Planning phase. See [plan.md](plan.md) for the full lesson-by-lesson mapping,
research findings, and decisions made so far. No code has been scaffolded
yet.

## Self-updating this file

Revise this AGENTS.md whenever meaningful decisions are made about the
project's structure, stack, or conventions. Once the Astro project is
scaffolded, expand this file to cover: stack details, script commands,
content authoring conventions, and deployment steps, following the pattern
of `agent-plan.md`/`AGENTS.md` from the opencode.school reference project.
Keep `plan.md` as the historical record of planning decisions; use this file
for the living technical reference once there's a codebase to describe.
